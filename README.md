# Симулятор гусеничной машинки с голосовым управлением

3D-модель чёрного купе на гусеничной раме и кольцевая дорога через всю карту 100×100 м.

**Трасса** (по ходу движения от жёлтой линии старта, отметки на краях — каждые 10 м):
1. длинная прямая ~80 м — разгон, «газ», «тормоз», «стоп»;
2. «налево», затем ещё раз «налево»;
3. «направо»;
4. плавный изгиб влево на 15° — три раза «левее»;
5. изгиб обратно на 15° — три раза «правее»;
6. «налево», «налево», «направо», «налево», «налево» — и снова старт.

Длина круга около 320 м. На панели слева видно, едет ли машинка по дороге
(если съехала — надпись красная и запись в журнале), пройденное расстояние
и тормозной путь последнего торможения («стоп», «тормоз» или аварийного).

## Что нужно установить

1. **.NET SDK версии 8 или новее** (подойдёт и .NET 10): https://dotnet.microsoft.com/download
   (или Visual Studio 2022 с нагрузкой «Разработка классических приложений .NET»).
2. **Русская модель Vosk**: на странице https://alphacephei.com/vosk/models
   скачайте `vosk-model-small-ru-0.22` (около 45 МБ).
   Распакуйте архив и переименуйте папку в `model`, положите её рядом с файлом
   `VoiceCarSim.csproj`. Внутри `model` должны лежать папки `am`, `conf`, `graph`…

Библиотеки Raylib-cs, Vosk и NAudio скачаются автоматически при первой сборке.

**Важно:** путь к папке проекта должен быть только из латинских букв, без пробелов
(например `C:\Projects\VoiceCarSim`). Vosk не умеет загружать модель из папок с
русскими или другими не-латинскими буквами в пути.

## Запуск

В папке проекта:

```
dotnet run
```

Или откройте `VoiceCarSim.csproj` в Visual Studio и нажмите F5.

Можно указать путь к модели явно: `dotnet run -- D:\models\vosk-model-small-ru-0.22`

Если модель не найдена или нет микрофона, программа всё равно запустится
и будет управляться с клавиатуры.

## Команды

| Голос     | Клавиша | Что делает |
|-----------|---------|------------|
| «прямо»   | W       | ехать вперёд, 5 км/ч |
| «газ»     | G       | +5 км/ч (максимум 15 вперёд, 5 назад) |
| «тормоз»  | B       | −5 км/ч; если скорость дошла до нуля — остановка |
| «стоп»    | Пробел  | плавная остановка, отмена поворота |
| «назад»   | S       | ехать назад, 3 км/ч |
| «направо» | D       | остановиться и повернуть на месте на 90° направо |
| «налево»  | A       | то же налево |
| «правее»  | E       | сместить курс на 5° вправо, не останавливаясь |
| «левее»   | Q       | то же влево |

Прочие клавиши: **C** камера (сзади / сверху / вся карта), **колесо мыши** — масштаб, **M** микрофон вкл/выкл,
**R** вернуть машинку в начало, **F1** скрыть подсказку.

Все скорости, углы и ускорения меняются в `Settings.cs`.

## Как устроена программа

```
Микрофон → VoiceRecognizer → CommandParser → CarController → SceneRenderer / Hud
 (NAudio)      (Vosk)        слово→команда     логика и движение       3D и интерфейс
                                                      ↑
                                       World: стены, препятствия, датчики
```

- `Voice/VoiceRecognizer.cs`: запись с микрофона 16 кГц и распознавание. Защита от
  ложных срабатываний на обычную речь:
  - Vosk распознаёт речь свободно, как обычный текст, и не подгоняет фразы под команды;
  - команда принимается, только если вся фраза — ровно одно слово-команда
    («давай поедем прямо» игнорируется и попадает в журнал как «Не команда»);
  - слова с низкой уверенностью распознавания отбрасываются;
  - исключение — «стоп»: срабатывает даже внутри фразы и уже по промежуточному
    результату, не дожидаясь паузы. Лишняя остановка безопасна, пропущенная — нет;
  - по желанию можно включить кодовое слово (`Settings.WakeWord`, например
    `"машина"` → «машина прямо»).
- `Voice/VoskNative.cs`: прямые вызовы libvosk со строками в UTF-8 (стандартная
  обёртка Vosk для C# портит русские буквы на Windows).
- `Control/CarController.cs`: состояние (стоит / вперёд / назад / поворот),
  плавный разгон и торможение, поворот на месте только после остановки,
  гусеничный привод: левая и правая гусеницы крутятся каждая со своей скоростью,
  руля нет (так же управляется и набор 4WD: левые колёса вместе, правые вместе),
  кинематика дифференциального привода (левое и правое колесо крутятся с разной скоростью).
  Класс не зависит от графики: в дипломе его можно подключить к реальным моторам.
- `Simulation/World.cs`: карта и дорога (осевая линия из прямых и скруглённых поворотов,
  проверка «на дороге / съехала»), ограждение по краю, имитация ультразвуковых датчиков
  (по три луча спереди и сзади). Если тормозной путь не помещается до препятствия,
  срабатывает аварийная остановка.
- `Rendering/`: 3D-модель из простых фигур: купе на гусеничной раме (бегущие траки,
  звёздочки, опорные катки с пружинами, трубчатые бамперы), след движения (красная линия),
  текущий курс (зелёная) и заданный курс (жёлтая), лучи датчиков, панели состояния.
- `CommandLog.cs`: журнал каждой сессии в `bin/.../logs/session_*.csv`
  (открывается в Excel). Пригодится для раздела «Испытания».

## Если что-то не работает

- **Кириллица на экране отображается вопросами**: не найден шрифт; программа ищет
  `C:\Windows\Fonts\segoeui.ttf` и `arial.ttf`.
- **Команды не распознаются**: проверьте, что в Windows выбран правильный микрофон
  по умолчанию (Параметры → Система → Звук → Ввод), и посмотрите, двигается ли
  индикатор громкости на экране. В консоли Vosk пишет предупреждения, если какого-то
  слова нет в модели.
- **Ошибка при загрузке Vosk / DllNotFoundException**: проект должен собираться
  как 64-битный (это уже указано в `.csproj`).
